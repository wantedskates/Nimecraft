For each class their are universal features that all instances of the class must have and some other specific features that not all the instances have. This is solved with subclasses, e.x., every creature have a health bar but not all creatures are hostile, so how can we translate that into code ? Some creatures might transform into other creatures , so under which condition does that happen ? Every class have methods, variables and constructors so what are those for each class ? How unique worlds are generated ? How different instances from different classes interact with each other? The details of each class is discussed in the folder of it.
