There are universal features that all generated worlds must have and other specific features that only some kind of worlds have. 

# Universal features 
1. Every world is unique
2. Each world has at least one biome from each class of different biomes 
3. Each world has respawning patterns
4. Each world has a state (e.x., crazy world, survival world, creative world ...etc)
5. Each world is infinite
6. Each world has altering states of weather
